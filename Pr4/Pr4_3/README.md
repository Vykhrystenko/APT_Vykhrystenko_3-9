# LinearSystems — варіант 4, Студент А

**Версія API:** 1.0  
**Призначення:** розв'язання квадратних систем лінійних рівнянь.

## 1. Призначення бібліотеки

`LinearSystems` — бібліотека мовою C++, призначена для розв'язання квадратних систем лінійних рівнянь виду:

Ax=b,

де:
- Aь - квадратна матриця коефіцієнтів розміром \(n\times n\);
- x — вектор невідомих;
- b — вектор правих частин;
- n — порядок системи.

Бібліотека реалізує метод Гаусса з частковим вибором головного елемента, обчислення евклідової норми 
нев'язки та перевірку точності знайденого розв'язку.

## 2. API та контракт

### 2.1. Загальні вимоги до вхідних даних

1. Система повинна бути квадратною.
2. Параметр `n` задає кількість рівнянь і невідомих та повинен бути додатним.
3. Матриця `A` передається як одновимірний масив довжини `n * n`.
4. Матриця зберігається в порядку рядків (*row-major*).
5. Масиви `b` та `x` повинні мати щонайменше `n` елементів.
6. Вказівники на обов'язкові масиви не повинні бути `nullptr`.
7. Користувач бібліотеки відповідає за коректність вказівників, розмірів масивів і вхідних числових даних.

Індекс елемента матриці в одновимірному масиві визначається формулою:

`A[row * n + col]`

де `row` — індекс рядка, а `col` — індекс стовпця. Індексація починається з нуля.

**Важливо:** реалізація не перевіряє фактичну довжину масивів або скінченність усіх елементів `A`, `b` та `x`. 
Ці вимоги повинен забезпечити користувач бібліотеки.

### 2.2. `gaussianElimination()`

**Сигнатура:**

`int gaussianElimination(double* A, double* b, int n);`

**Призначення:** виконує прямий хід методу Гаусса з частковим вибором головного елемента, перетворюючи матрицю на верхньотрикутну.

**Параметри:**
- `A` — матриця коефіцієнтів розміром `n * n`;
- `b` — вектор правих частин довжини `n`;
- `n` — порядок системи.

**Поведінка:** функція модифікує масиви `A` та `b`. 
Під час вибору опорного елемента використовується перестановка рядків.

**Значення, що повертається:**
- `1` — прямий хід завершено успішно;
- `0` — виявлено некоректні базові аргументи або опорний елемент, модуль якого не перевищує `1e-12`.

Якщо функція повертає `0`, масиви `A` та `b` можуть уже містити частково виконані перетворення. 
Для повторної спроби слід використати початкові дані.

### 2.3. `solve()`

**Сигнатура:**

`int solve(const double* A, const double* b, int n, double* x);`

**Призначення:** знаходить розв'язок системи `Ax = b` методом Гаусса.

**Параметри:**
- `A` — початкова матриця коефіцієнтів;
- `b` — початковий вектор правих частин;
- `n` — порядок системи;
- `x` — вихідний масив для збереження знайдених невідомих.

**Поведінка:** функція створює копії матриці та вектора правих частин, виконує прямий хід і зворотну підстановку. 
Початкові масиви `A` та `b` не змінюються.

**Значення, що повертається:**
- `1` — розв'язок успішно обчислено та записано в `x`;
- `0` — некоректні базові аргументи або виявлено опорний елемент, модуль якого не перевищує `1e-12`.

У разі помилки не слід використовувати `x` як гарантовано коректний розв'язок. Під час невдалого виклику частина елементів `x` може бути змінена.

### 2.4. `residual()`

**Сигнатура:**

`double residual(const double* A, const double* b, const double* x, int n);`

**Призначення:** обчислює евклідову норму нев'язки для заданого наближеного розв'язку.

**Параметри:**
- `A` — матриця початкової системи;
- `b` — вектор правих частин початкової системи;
- `x` — перевірюваний вектор розв'язку;
- `n` — порядок системи.

**Значення, що повертається:**
- невід'ємне число — обчислена норма нев'язки за коректних аргументів і скінченного результату;
- `-1` — хоча б один обов'язковий вказівник дорівнює `nullptr` або `n <= 0`.

Якщо вхідні числові дані містять нескінченність або `NaN`, результат може бути нескінченним або `NaN`. Такі дані не перевіряються окремо.

Чим ближча нев'язка до нуля, тим краще обчислений вектор задовольняє початкову систему. Мала нев'язка сама по собі не гарантує малої похибки розв'язку для погано обумовленої матриці.

### 2.5. `checkSolution()`

**Сигнатура:**

`int checkSolution(const double* A, const double* b, const double* x, int n, double tolerance);`

**Призначення:** перевіряє, чи не перевищує норма нев'язки заданий допустимий рівень.

**Параметри:**
- `A` — матриця початкової системи;
- `b` — вектор правих частин;
- `x` — перевірюваний розв'язок;
- `n` — порядок системи;
- `tolerance` — допустима нев'язка, скінченне невід'ємне число.

**Значення, що повертається:**
- `1` — аргументи пройшли перевірки, нев'язка скінченна та не перевищує допуск;
- `0` — допуск некоректний, аргументи не пройшли перевірки або нев'язка перевищує допуск.

Функція `checkSolution()` використовує `residual()` для обчислення нев'язки.


## 3. Приклад використання

```cpp
#include "LinearSystems.h"
#include <iostream>

int main() {
    // Система:
    // 2*x1 + x2 = 5
    // x1 - x2 = 1

    const double A[] = {
        2.0,  1.0,
        1.0, -1.0
    };

    const double b[] = {5.0, 1.0};
    double x[2]{};

    if (!solve(A, b, 2, x)) {
        std::cerr << "Не вдалося розв'язати систему.\n";
        return 1;
    }

    const double r = residual(A, b, x, 2);
    const int valid = checkSolution(A, b, x, 2, 1e-9);

    std::cout << "x1 = " << x[0] << '\n';
    std::cout << "x2 = " << x[1] << '\n';
    std::cout << "Residual = " << r << '\n';
    std::cout << "Checked = " << valid << '\n';

    return 0;
}
```

Очікуваний результат:

```text
x1 = 2
x2 = 1
Residual = 0
Checked = 1
```

Незначна відмінність нев'язки від нуля можлива через особливості обчислень із типом `double`.

## 5. Підключення бібліотеки

Для використання функцій у вихідному коді клієнтської програми необхідно підключити заголовок:

```cpp
#include "LinearSystems.h"
```
Компілятор повинен мати доступ до каталогу із заголовковим файлом, а компонувальник до відповідної реалізації бібліотеки.
