## 1. Назва проєкту та короткий опис
**Car Simulation** — проєкт, що реалізує імітаційне моделювання розгону та гальмування автомобіля в реальному часі на основі чисельного методу Ейлера. 

## 2. Основні можливості / Функціонал
* **Динамічне керування силами:** Можливість плавно змінювати силу тяги та силу гальмування за допомогою клавіатури під час роботи програми.
* **Чисельне інтегрування:** Розрахунок прискорення, швидкості та координати за допомогою дискретного кроку часу (dt = 1/60 с).
* **Візуалізація траєкторії:** Відображення переміщення автомобіля дорогою, фінішної лінії та автоматичне малювання сліду траєкторії руху.
* **Інформаційна панель:** Динамічний вивід поточних числових показників (позиція, швидкість, пройдена дистанція, час симуляції, гальмівний шлях) у реальному часі.
* **Керування станом симуляції:** Можливість ставити симуляцію на паузу, відновлювати її або повністю скидати до початкових параметрів.

## 4. Інструкція з керування (Управління)
Для керування симуляцією використовуються такі клавіші на клавіатурі:
* **Стрілка вгору / вниз (UP / DOWN):** Збільшення / зменшення сили тяги (+/- 5).
* **Стрілка вправо / вліво (RIGHT / LEFT):** Збільшення / зменшення сили гальмування (+/- 5).
* **Клавіша ENTER:** Запуск, пауза або продовження симуляції.
* **Клавіша SPACE (Пробіл):** Повне скидання симуляції до початкового стану (зі збереженням налаштованих сил).
